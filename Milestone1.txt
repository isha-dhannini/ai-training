=== SECTION A — PROBLEM STATEMENT ===
    5-stage pipeline :
	    Ingest -> Structure -> Store -> Summarise -> Visualise.
    1. It is designed to transform unstructured data from a PDF into structured and 
    clear visual data.
    2. INGEST stage - PDF is opened and plain text is extracted from all pages.
    3. STRUCTURE stage - The extracted text is organized into a tabular format with data 
    suchas word counts, page number.
    4. STORE stage - The structured data is stored as JSON/CSV files.
    5. SUMMARIZE stage - Text is set as prompt ans sends to an LLM via Groq API to generate 
    summary.
    6. VISUALISE stage - Bar chart is generated to show mapped data for example, the word 
    count for each page.


=== SECTION B — ARCHITECTURE DIAGRAM ===
    [./data/report.pdf] -->[Ingest] - raw text per page --> [Structure] - Dataframe 
    -->[Store] --> output/files --> [Summarise] --> Groq LLM Response 
    --> [ Visualise] --> Matplotlib Bar chart


=== SECTION C — CODE BLOCKS ===

    C1. LOGGING SETUP: 

    ```python
    import logging
    logging.basicConfig(level= logging.INFO)
    ```

    C2. INGEST + EXTRACT:
    
    ```python 
    import fitz # pip install pymupdf
    pdf_path = "./data/report.pdf"
    page_texts = []

    try:
        doc = fitz.open(pdf_path)   #Open the PDF
        print(f"Pages : {len(doc)}")
        print(f"Title : {doc.metadata['title']}")
        print(f"Author: {doc.metadata['author']}")
        
        # Extract text from every page
        for page_num, page in enumerate(doc, start=1):
            text = page.get_text()          # plain UTF-8 string
        page_texts.append(text)
    except Exception as e:
        logging.error(f"Error extracting text from PDF: {e}")
    doc.close()
    ```

    C3. STRUCTURE:
            
    ```python
    import pandas as pd

    data = []
    for i, text in enumerate(page_texts, start=1):
        data.append({
            "page_no": i,
            "word_count": len(text.split()),
            "first_50_chars": text[:50]
        })
    df = pd.DataFrame(data)
    ```
    
    C4. STORE:
    
    ```python
    import os

    os.makedirs("output", exist_ok = True)
    df.to_csv("output/pages.csv", index = False)
    df.to_json("output/pages.json", orient="records")
    ```

    C5. SUMMARISE WITH GROQ:
    ```python
    from groq import Groq
    import os

    client = Groq(api_keys=os.environ["GROQ_API_KEY"])

    combined_text = " ".join(page_texts)[:2000]

    response = client.chat.completions.create(
        model = "llama-3.1-8b-instant",
        messages = [
            {
                "role": "user",
                "content": f"Summarise this exactly in 3 bullet points.\n\n{combined_text}"
            }
        ]
    )
    print(response.choices[0].message.content)

    ```

    C6. VISUALISE:
    ```python
    import matplotlib.pyplot as plt
    fig, ax = plt.subplots(figsize=(6, 4))

    bars = ax.bar(df["page_no], df["word_count])

    for bar, val in zip(bars,  df["word_count]):
        ax.text(
            bar.get_x() + bar.get_width() / 2,
            bar.get_height(),
            f"{val}",
            ha='center',
            va='bottom',
            fontsize=11,
            fontweight='bold'
        )

    ax.set_title('Word Count Per Page')
    ax.set_xlabel('Page Number')
    ax.set_ylabel('Word Count')

    plt.show()
    ```


=== SECTION D — EXPECTED GROQ RESPONSE SHAPE ===
    The Groq API will print summary in exactly 3 bullet points.
    1. First bullet point describes main topic/prupose of the document.
    2. Second bullet will highlight the key data, important information from report.
    3. Third bullet point will summarize the next steps or conclusions of the report.


=== SECTION E — LESSONS LEARNED ===

    structures into pandas and stored as CSV and JSON files.
